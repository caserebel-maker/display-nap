# 🌙 DisplayNap for macOS

> **แอปพักหน้าจออัตโนมัติบนแถบเมนู (Menu Bar) สำหรับ macOS**  
> ปิดเฉพาะจอภาพเพื่อประหยัดพลังงาน **โดยที่เครื่องและโปรแกรมเบื้องหลังยังคงทำงานต่อเนื่อง 100% (ไม่ Sleep เครื่อง ไม่ตัดเน็ต ไม่หยุดโปรเซส)**

---

## ✨ ไฮไลท์ฟีเจอร์ (Key Features)

- ⏱️ **Preset เวลาสำเร็จรูป**: เลือกได้ทันทีไม่ต้องพิมพ์บ่อยๆ:
  - `5 นาที`
  - `10 นาที`
  - `15 นาที`
  - `30 นาที`
  - `60 นาที (1 ชั่วโมง)`
  - และตัวเลือกเสริมอื่นๆ: `1 นาที (สำหรับทดสอบ)`, `20 นาที`, `45 นาที`, `90 นาที`, `120 นาที`, `180 นาที`
- ✏️ **กำหนดเวลาเองได้ (Custom Time)**: ระบุจำนวนนาทีที่ต้องการได้อิสระ
- 🕒 **Live Menu Bar Countdown**: แสดงตัวเลขนับถอยหลังสดๆ บน Menu Bar (เช่น `🌙 14:45`) เหลือบมองได้ตลอดเวลา
- ⚡ **พักหน้าจอทันที**: กดคลิกเดียวพักหน้าจอทันที (`⌘⌥S`)
- 🛑 **ยกเลิกได้ทุกเมื่อ**: มีปุ่ม Cancel Timer
- 🔔 **ระบบแจ้งเตือน**: แจ้งเตือนเมื่อเริ่มนับถอยหลัง และแจ้งเตือนล่วงหน้า 10 วินาทีก่อนพักหน้าจอ
- 💻 **เครื่องยังคงทำงานปกติ**: ใช้คำสั่งระบบ macOS `pmset displaysleepnow` โดยเฉพาะ จอดับแต่ CPU, Network, Background Tasks, AI Processing ยังคงทำงานเต็มสปีด
- ⌨️ **แถมฟรี CLI Utility**: สั่งงานผ่าน Terminal ได้ด้วยคำสั่ง `displaynap 15`

---

## 🚀 วิธีติดตั้งอย่างง่าย (Quick Install)

เปิด **Terminal** บนเครื่อง Mac (ที่ทำงานหรือที่บ้าน) แล้วพิมพ์คำสั่งเดียว:

```bash
git clone https://github.com/caserebel-maker/display-nap.git
cd display-nap
./install.sh
```

สคริปต์จะคอมไพล์โค้ด Swift ดั้งเดิม (Native App) และติดตั้งเข้าโฟลเดอร์ `/Applications` (หรือ `~/Applications`) และเปิดแอปขึ้นแถบเมนูให้อัตโนมัติทันที!

> 💡 **หมายเหตุ**: ไม่ต้องลงเครื่องมือเสริมใดๆ เพิ่มเติม macOS มี Swift Compiler ติดมากับระบบอยู่แล้ว

## 🖥️ การใช้งาน Menu Bar App

1. สังเกตไอคอนดวงจันทร์ `🌙` บนแถบ Menu Bar ด้านบนขวาของหน้าจอ
2. คลิกที่ไอคอน จะมีเมนูปรากฏขึ้น:
   - เลือกเวลาที่ต้องการ เช่น **"⏱️ 15 นาที"**
   - หรือกด **"⚡ พักหน้าจอทันที"**
3. เมื่อเริ่มนับถอยหลัง ไอคอนจะแสดงเวลาที่เหลือ เช่น `🌙 14:59`
4. หากต้องการยกเลิก ให้คลิกไอคอนแล้วกด **"🛑 ยกเลิกตัวนับเวลา"**

---

## ⌨️ การใช้งานผ่าน Terminal CLI (อุปกรณ์เสริม)

หลังติดตั้ง สามารถพิมพ์สั่งงานใน Terminal ได้ทันที:

```bash
# พักหน้าจอในอีก 15 นาที
displaynap 15

# พักหน้าจอในอีก 5 นาที
displaynap 5

# ดูเวลาที่เหลือ
displaynap status

# ยกเลิกการนับถอยหลัง
displaynap cancel

# พักหน้าจอทันที
displaynap now
```
